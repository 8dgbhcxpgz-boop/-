## Image mapping template
For each uploaded reference, record: filename, asset, role, angle, verified visible features, pixel crop coordinates, unknown details and conflict flag. The ledger above is NOT a substitute for reference image pixels.

## Strict source policy
Do not mix the alternate ruffle-front dress shown in some reference photos into the target floral slip dress. Do not assume unseen stitching, zipper placement or exact fabric composition. No generation without available original image files and selected source IDs.

## Approval
Visual compare product crops vs output crops at same scale. FAIL if any locked motif or construction drifts. If image model cannot use actual reference pixels, stop rather than advertise a generic image as high-fidelity try-on.
